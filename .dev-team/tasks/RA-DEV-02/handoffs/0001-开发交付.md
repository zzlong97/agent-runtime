## 本批实现

受信 Adapter 进入现有 Gateway/Parent/Run：首次只发送当前 Human 文本，稳定 UUIDv5
messageId。来源及身份 hash 在新 started 中先提交；重建复用原值，不回填旧事件。
绑定提交先于 Send Operation 成功退出；已有绑定只 Get，绑定后仍 pending 的账本可
依已确认结果对账。远程事实使用固定内部 Schema、专用归属/幂等事务，不进入 SSE/Redis。

未知结果跨 Gateway、强制取消、超时、恢复和删除保持活动态；远程计数可超过三次并
退避，本地三次限制保留。身份/来源替换、旧缺凭据、配置缺失或替换成本地实现都不能
放开未知远程任务。取消意图仅内部持久区分 explicit/timeout，首个事务获胜；确认后
分别保留 cancelled/stopped 与 CAPABILITY_TIMEOUT/failed/incomplete。删除未知返回
可重试 409；公共 AI 仍由 Parent 写入且使用同一稳定 ID。

显式远程 OUT_OF_SCOPE 在 Get 确认后执行批准窄例外：同一事务锁定/复核精确归属，
只清理本次稳定 Send，恢复原 current、回滚 provisional Task，并写拒绝内部结果。
绑定/终态证据保留；额外业务/Cancel/其他 Send、归属错、失败行、输出或 Child Checkpoint
均不能部分清理。本地零 Operation 门禁不变。提交前后崩溃按同 ID 对账，不再 Send。

直接调用链额外修正：CapabilityError 允许 contextlib 必需的标准 traceback 更新，
业务字段仍只读；否则超时码会被 AttributeError 覆盖。SDK/R01 脱敏边界保留。
