## 1. 锁定协议与 SDK 的实施输入

本轮实际读取官方原始源码和包元数据，不使用 0.3 示例推测 1.0：

- 协议选择 A2A **v1.0.1**，Git tag 指向
  `3303592588e388e62e0f69f701af531d2f4e3991`：
  [官方 proto](https://github.com/a2aproject/A2A/blob/3303592588e388e62e0f69f701af531d2f4e3991/specification/a2a.proto)。
- 官方 Python 包锁定输入为 **a2a-sdk==1.2.3**，源码提交
  `44b2f761a99123370237afe6c828f4cd2a50c402`：
  [SDK 依赖](https://github.com/a2aproject/a2a-python/blob/44b2f761a99123370237afe6c828f4cd2a50c402/pyproject.toml)、
  [REST transport](https://github.com/a2aproject/a2a-python/blob/44b2f761a99123370237afe6c828f4cd2a50c402/src/a2a/client/transports/rest.py)、
  [PyPI 包元数据](https://pypi.org/pypi/a2a-sdk/1.2.3/json)。
  包声明 Python >=3.10，支持项目 Python 3.12；要求 httpx>=0.28.1、pydantic>=2.11.3、
  protobuf>=5.29.5。当前环境 httpx=0.28.1、pydantic=2.13.5，尚未安装 a2a-sdk/protobuf。
  这证明源码/声明兼容，**不代表已经安装或完成依赖解析**。RA-DEV-01 实际解析、锁定
  pyproject/uv.lock 并跑官方类型/REST 互操作测试；不安装 all、gRPC、数据库等无当前用途的 extra。
- SDK Factory 自带旧版回退选择，Runtime 必须先筛选合规接口并固定 REST transport，
  禁止让默认协商落入 JSONRPC、旧版兼容模块或流式分支。

以下为开发必须使用的真实 wire 映射（Python proto 名称用 snake_case，JSON 用 camelCase）：

| 项目 | A2A 1.0 HTTP+JSON 形态 |
| --- | --- |
| Agent Card | `supportedInterfaces[]` 的元素含 `url/protocolBinding/protocolVersion`；不是顶层 protocolVersion/url 或 preferredTransport |
| 兼容接口 | `protocolBinding="HTTP+JSON"`、`protocolVersion="1.0"`；规范锁到 patch 1.0.1，请求头仍为 `A2A-Version: 1.0` |
| Send | 在所选接口 base URL 下 `POST /message:send`；body `message + configuration`，非 JSON-RPC envelope |
| 非阻塞 | `configuration.returnImmediately=true`，不是旧版 blocking=false；`acceptedOutputModes=["text/plain"]` |
| Message | `messageId`、`role="ROLE_USER"`、`parts=[{"text":"…"}]`；续发加同一 `taskId/contextId` |
| Send 响应 | `{"task":{...}}` 或 `{"message":{...}}`；本 Profile 要求可恢复 Task，不能把裸 Message 当合规长任务 |
| Get | `GET /tasks/{id}`，返回 Task；Task 主键字段是 `id`，另有 `contextId` |
| Cancel | `POST /tasks/{id}:cancel`，返回 Task；不是 /tasks/cancel 或 tasks/get RPC 方法 |
| 状态 | wire 为 `TASK_STATE_SUBMITTED/WORKING/COMPLETED/FAILED/CANCELED/INPUT_REQUIRED/REJECTED/AUTH_REQUIRED`；本地显式转换，不直接比较旧版小写或连字符字符串 |
| 补参 | `Task.status.message.messageId` 和非空文本 parts；必须保留同一次 input-required 的稳定身份 |
| 结果 | `Task.artifacts[].artifactId/parts[].text`，按顺序拼接；不消费 data/raw/url 部分 |

SDK 还支持接口 tenant 路径前缀；若 Card 提供 tenant，保持官方 transport 路径规则，不新增
本项目租户概念/配置。Card 没有“可用操作列表”字段；三操作可用性由 Fake/对方契约用例验证，
不能仅凭 Card 声称 Send/Get/Cancel 都已可用。幂等保证也是强制 Profile 要求，不是 SDK 自带保证。

Agent Card/认证最小测试矩阵：

- URL 仅 HTTP(S)，拒绝 userinfo、片段、越界调用地址和不受控重定向；origin 按 scheme、
  规范化 host、有效 port 比较，路径不参与 origin。先验证目标再发送凭据；Card 拉取同样受控。
- 默认同源；只有出现当前实际不同源接入需要时才实现已批准的显式来源白名单，不为假设预建
  泛化信任服务。若允许额外 origin，凭据只到明确受信目标，不能跟随跳转泄露。
- none 必须显式开发允许；生产默认 HTTPS/Bearer。现有 `runtime_demo_mode` 会绕过正式
  Router，不能拿它代替远程开发安全开关。所需最小开发安全配置有当前 Fake/本地接入使用方。
- Bearer 对应 Card `securitySchemes.*.httpAuthSecurityScheme.scheme` 与
  `securityRequirements[].schemes`；校验可满足的一组要求。拒绝缺失 token 环境引用、
  不支持的强制认证和 required extension；Token 值不进入 Card/Manifest 快照、异常或日志。
- 非法/不可达/身份或接口不兼容只隔离该 Entry；刷新 Card 仅更新 Health，不替换静态身份。

恢复判定必须覆盖 **已受理但未写 task_bound** 的 open remote Invocation：按请求9.3、
RA-AC-05 和 D-067 的未知结果原则，不能只凭“存在 task_bound”才豁免 3 次终止上限。
