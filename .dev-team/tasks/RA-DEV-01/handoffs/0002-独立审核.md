## 阻塞问题 RA-DEV-01-R01

- 严重程度：重要 / 阻塞；类型：实现安全缺陷；建议责任：dev-team-developer。
- 位置：`src/agent_runtime/capabilities/remote_a2a/client.py:74`（只登记请求/响应 hook）与
  `:146`（SDK 调用退出后才替换异常）；现有 `:100` 的响应 hook 无法覆盖响应头解析失败。
- 预期：RA-AC-07 协议/安全部分及 task.md 要求凭据、正文与原始解析错误不进入 SDK 遥测。
- 实际：非法 HTTP 状态行/响应头由 h11/httpcore/httpx 在响应 hook 之前抛异常。官方 SDK
  `handle_http_exceptions` 把 `httpx.RequestError` 原文嵌入 `A2AClientError`，随后
  `RestTransport` 的 `trace_class` 记录异常和状态说明；外层 `_call` 此后脱敏已来不及。
  业务日志与公开错误文案虽已脱敏，SDK 遥测仍包含远程原始字节，配置 tracing 导出后会进入遥测。
- 独立离线复现：用安装的 h11 实际解析带测试标记的非法状态行，经 MockTransport 映射
  httpx.RemoteProtocolError；Send 返回固定 `CAPABILITY_REMOTE_UNAVAILABLE`，公开错误
  不含标记，但 SDK 的 **3 条异常记录均含标记**。未使用真实凭据、数据库或网络服务。
- 复核：在 SDK 进入异常遥测之前建立受控 HTTP 异常边界；补充非法状态行和非法响应头的
  Send/Get/Cancel 离线回归，检查 record_exception、set_status 说明及完整异常链/堆栈
  均不含测试标记，并保留既有网络可重试、401/403、JSON/Schema 脱敏用例。不限定具体实现。

复现命令：PowerShell 将下面脚本通过标准输入交给 `.\.venv\Scripts\python.exe -`，退出 0。

```python
import asyncio
from contextlib import contextmanager
import h11
import httpx
from a2a.utils import telemetry
from agent_runtime.capabilities.remote_a2a.client import RemoteA2AClient, RemoteA2AError
from agent_runtime.capabilities.manifest import RemoteA2ATransport
from tests.fake_a2a import FakeA2A, remote_transport

marker = "REVIEW_REMOTE_PRIVATE_BODY"
recorded = []
class Span:
    def set_status(self, *args, **kwargs): pass
    def record_exception(self, error): recorded.append(str(error))
class Tracer:
    @contextmanager
    def start_as_current_span(self, *args, **kwargs): yield Span()
telemetry.trace.get_tracer = lambda *args: Tracer()
fake = FakeA2A()
def handle(request):
    if request.url.path.endswith("/message:send"):
        conn = h11.Connection(h11.CLIENT)
        conn.receive_data((marker + "\r\n\r\n").encode())
        try:
            conn.next_event()
        except h11.RemoteProtocolError as error:
            raise httpx.RemoteProtocolError(str(error), request=request) from error
    return fake.handle(request)
async def run():
    client = RemoteA2AClient(capability_id="remote_test",
        transport=RemoteA2ATransport.model_validate(remote_transport()),
        development_mode=True, http_transport=httpx.MockTransport(handle))
    try:
        await client.discover()
        try:
            await client.send_message(message_id="review-id", text="input")
        except RemoteA2AError as error:
            print(error.code, marker in str(error), len(recorded),
                  sum(marker in value for value in recorded))
    finally:
        await client.close()
asyncio.run(run())
# 实际：CAPABILITY_REMOTE_UNAVAILABLE False 3 3
```
