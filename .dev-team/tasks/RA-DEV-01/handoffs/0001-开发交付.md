## 实现与边界

Manifest 改为 local/remote_a2a 关闭联合，拒绝旧顶层 entrypoint，远程只允许 invocation；
两个内置 Manifest、原测试夹具及接入手册同步迁移。Registry 从 Runtime 受信工厂创建
远程 Client，沿用健康 TTL、故障隔离和四字段 Router 投影，远程不分配 Child 基础设施。

官方 a2a-sdk==1.2.3 已通过 uv 实际解析锁定，不启用 extra；固定 A2A v1.0.1 的
HTTP+JSON RestTransport，覆盖 Card、非阻塞 Send、Get、Cancel、tenant、文本 Profile。
来源/认证在发送凭据前校验，只允许同源、拒绝全部重定向和未支持的 required extension；
Token 仅在受信 Client 内解析。Card 刷新不替换启动身份或接口。

新增独立于 demo 的默认关闭开发安全开关及全局 HTTP 超时；Registry 组装后即注册
异常出口清理。remote Regenerate 由真实提交校验在 Run/Parent Fork 前返回 409。
保留了 SDK 遥测原始解析值脱敏回归；固定内部异常避免不可变 CapabilityError 与 SDK
上下文管理器写 traceback 的冲突。业务日志使用既有中文脱敏入口，Send 带稳定 message_id。
