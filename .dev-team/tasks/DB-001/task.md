# DB-001 补充并修正数据库表注释

## 目标与范围

根据负责人 2026-10-17 的请求，为当前项目创建的数据库表补充准确的表注释，并修正
负责人此前填入但含义有误的表注释。需求已获负责人批准，覆盖 9 张项目业务表的精确
中文表注释及 4 张依赖内部表的排除边界；未经批准不修改已确认架构决策、Stage 边界
或数据库结构语义。

## 业务验收

需求基线见本任务 `requirements.md`，精确批准版本以 `state.yaml` 为准。
业务验收为 DBA-001～006：9 表范围完整、精确中文注释、旧注释替换、既有库/新库/
重复执行一致、排除对象不变、结构与业务数据不变。表注释逐字以批准需求第 4 节为准。

## 基线与技术约束

需求和架构正文继续以 `docs/requirements.md`、`docs/architecture.md`、
`docs/decisions.md` 为权威来源；精确版本和批准状态以本任务 `state.yaml` 为准。
数据库使用 PostgreSQL；不得删除或重置 `agent-runtime-postgres` 命名卷，不得自行
修复或重置 Docker Desktop。新增或修改的代码文本、迁移说明和用户可见提示使用中文。

## 实施拆解

已批准架构见本任务 `architecture.md`，技术验收 DBT-001～007、最小开发单元
`DB-001-DEV-01` 见其第 5、6 节。候选沿用所属 Repository 的幂等 setup，在既有
事务 commit 前重申固定 COMMENT；覆盖现有库、新库和重复执行，失败必须上抛并有

数据摘要。批准版本与批准来源以本任务 state 为准。
